Protocolo HTTP

O que é HTTP?

HTTP significa Hypertext Transfer Protocol. É um protocolo utilizado para a comunicação entre o navegador (cliente) e os servidores na Web.

Quando acessamos um site, o navegador envia uma requisição (request) para o servidor. O servidor processa a solicitação e envia uma resposta (response).

Exemplo de Request

GET /index.html HTTP/1.1 Host: [www.exemplo.com](http://www.exemplo.com) User-Agent: Mozilla/5.0 Accept: text/html ```

GET: solicita uma informação ao servidor.
Host: informa o endereço do servidor.
User-Agent: identifica o navegador utilizado.
Accept: informa o tipo de conteúdo aceito.

Exemplo de Response


HTTP/1.1 200 OK
Content-Type: text/html
Content-Length: 1250




Olá, mundo!

200 OK: significa que a requisição foi realizada com sucesso.
Content-Type: informa o tipo do conteúdo enviado.
Content-Length: informa o tamanho do conteúdo.

Captura de uma requisição

Para visualizar uma requisição HTTP, podemos abrir as ferramentas de desenvolvedor do navegador pressionando F12 e acessar a aba Network (Rede).

Ao acessar uma página, podemos observar informações como:

  • Método utilizado, como GET ou POST;
  • URL acessada;
  • Headers da requisição;
  • Headers da resposta;
  • Código de status;
  • Conteúdo enviado ou recebido.

Principais códigos HTTP

  • 200 - Requisição realizada com sucesso.
  • 201 - Recurso criado.
  • 400 - Requisição inválida.
  • 401 - Autenticação necessária.
  • 403 - Acesso proibido.
  • 404 - Página ou recurso não encontrado.
  • 500 - Erro interno do servidor.

Conclusão

O HTTP é fundamental para o funcionamento da Web, pois permite que navegadores e servidores troquem informações. Através das requisições e respostas, é possível acessar páginas, enviar dados, carregar imagens, vídeos e utilizar aplicações Web.
